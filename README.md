## Reproducibility standard

Projects should provide, where applicable:

- a clear research question;
- documented data sources and retrieval dates;
- a baseline model;
- temporal train/test separation for financial data;
- explicit treatment of transaction costs and slippage when a strategy is simulated;
- out-of-sample results;
- a reproducible environment;
- limitations and failure modes;
- a security check showing that no credentials are included.

The Market Regime and Risk Lab provides a pinned `requirements.txt`, reproducible Python scripts, final CSV outputs, figures and English/French LaTeX reports.
