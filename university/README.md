# University projects

This directory contains selected coursework and exploratory analyses from the Mathematics & Economics degree.

## Selected work

- [Monte Carlo & Black–Scholes](./Projet%20-%20Simulation%20Monte%20Carlo%20%26%20Black-Scholes.py) — simulation and derivative pricing.
- [Financial time-series econometrics](./Analyse%20%C3%A9conom%C3%A9trique%20de%20s%C3%A9ries%20financi%C3%A8res.py) — returns, volatility and autocorrelation analysis.

The files are academic experiments rather than production libraries. The projects intended for admissions evidence should include a README, reproducible environment, tests where appropriate and a clear discussion of assumptions and limitations.
